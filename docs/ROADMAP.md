# Roadmap

## Done
**v0.1** Timer engine, foreground-service runner, strong haptics + optional sound, pause logging, presets, alarms, heart rate, stats, workout-times screen, settings.
**v0.2** New look (black + mint, cards, progress ring, round dots) · alerts at any time you choose (watch editor) · free-form Custom timers
(blocks, named steps, alerts as time-left or time-since-start) · phone app (editor + stats) · phone <-> watch sync · `:shared` module.

**v0.3** Alarms sync between phone and watch (Alarms tab + editor on the phone) · fix: app crashed on launch after saving an alarm (exact-alarm permission; scheduling can no longer crash the app) ·
roomier layouts with titled sections on watch and phone (labelled steppers, ⋮ menus for move/delete).

**v1.0** Quick-start **Tile** (your 3 latest timers) · **Next-alarm complication** · crown/bezel editing in steppers (tap a value, turn the crown) ·
**voice cues** (optional, for earbuds) · **backup / restore / share** (phone) · **"every N seconds"** alerts (phone) · 12-hour alarm editor (AM/PM) · performance pass
(per-timer caching, optimised release build + baseline profile).

## Ideas for later
* Complication for the running timer; more Tile layouts (favourites you pick yourself).
* "Every N seconds" alerts in the watch editor.
* Export history as CSV.

## Deliberately left out
Always-on display (battery), accounts/cloud, ads/analytics.
